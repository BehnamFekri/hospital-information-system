# Hospital Information System

A generic reference project for Hospital Information Systems (HIS), based on practical healthcare IT concepts.

## Scope

- Patient reception
- Admission and discharge
- Clinical workflows
- Nursing
- Paraclinical services
- Medical records
- Billing and financial workflows
- Physician services
- Reporting
- Data quality

## Structure

- `database-design/`
- `reception/`
- `admission-discharge/`
- `billing/`
- `medical-records/`
- `reporting/`
- `data-quality/`

## Goal

Document reusable HIS concepts, data models, workflows and technical patterns without exposing any real hospital implementation.

## Confidentiality

This repository intentionally contains no patient data, credentials, server names, internal addresses or proprietary production schema.
